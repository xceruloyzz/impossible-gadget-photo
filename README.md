# HOVERBREW — Catalogue Photo of an Impossible Gadget

A studio catalogue photograph of an impossible gadget: the HOVERBREW mug, a matte-white ceramic mug whose coffee levitates above it as a single glossy sphere, with two droplets suspended mid-air and thin curls of steam rising from the orb. One small spoon lies beside the mug — the only accessory in the shot.

Rendered deterministically in pure Python (standard library only) by `main.py`, which writes a 1024×1024 PNG to `/output/entry.png`.
